# AyTube Cookie Exporter (Browser Extension) 🍪

A lightweight, zero-bloat browser extension to export YouTube session cookies in standard Netscape format for **AyTube**, **yt-dlp**, and **curl** in a single click.

---

## 🚀 How to Install in Chrome / Brave / Edge (30 Seconds)

1. Open your browser and go to:
   - **Chrome:** `chrome://extensions/`
   - **Brave:** `brave://extensions/`
   - **Edge:** `edge://extensions/`

2. Turn on **Developer mode** (toggle switch in the top-right corner).

3. Click **"Load unpacked"** (top-left).

4. Select this `extension` folder from your repository:
   ```text
   /path/to/AyTube/extension
   ```

5. Done! The **AyTube Cookie Exporter** icon will now appear in your browser toolbar.

---

## 🎯 How to Use

1. Open [youtube.com](https://www.youtube.com) and ensure you are logged in to your account.
2. Click the **AyTube Exporter** extension icon.
3. Click **"Download cookies.txt"**.
4. Save the file directly as `cookies.txt` inside your `AyTube` project folder.
5. That's it! AyTube will automatically detect `cookies.txt` and bypass bot checks and rate limits.

---

## 🛡️ Privacy & Security

- **100% Local Execution:** The extension runs entirely in your browser.
- **Zero Network Requests:** It does not send your cookies or any data anywhere.
- **Open Source:** Clean, readable HTML and vanilla JavaScript.
